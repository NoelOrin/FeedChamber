## MODIFIED Requirements

### Requirement: 导航与首页模块由配置驱动

站点的导航项与首页模块 MUST 由配置数据驱动渲染，而非硬编码在组件中。导航项 MUST 支持标签、目标地址、图标、排序与可见性（公开 / 仅登录 / 指定等级及以上）。首页模块 MUST 支持类型、排序与可见性。

公共壳层（侧边栏、顶栏、页脚）MUST 提供具名插槽，插槽内容 MUST 由配置数据驱动，
按 `shell-slots` 规范渲染。插槽条目类型 MUST 限于结构化条目，MUST NOT 接受裸 HTML。

当导航配置与插槽配置均为空时，系统 MUST 回退到既有硬编码的默认导航、首页布局与壳层布局，
MUST NOT 呈现空白导航、空白首页或空白壳层区域。

#### Scenario: 自定义导航项出现在前台

- WHEN 站长新增一个可见性为公开的导航项
- THEN 前台导航 MUST 显示该项，并按排序权重排列

#### Scenario: 可见性受限的导航项对游客隐藏

- WHEN 某导航项的可见性为「仅登录」
- THEN 未登录访问者 MUST NOT 看到该项
- AND 已登录用户 MUST 看到该项

#### Scenario: 无配置时回退默认

- WHEN 导航配置为空且插槽配置为空
- THEN 前台 MUST 渲染既有的默认导航项与默认壳层布局，MUST NOT 渲染空导航或空壳层
