## Stack

| Layer | Choice |
|-------|--------|
| Backend | Go 1.25 + [Iris v12](https://www.iris-go.com/), handler / service / repository layers, GORM for SQL |
| Frontend | React 19 + vinext (App Router), TanStack Query, shadcn-style primitives, Tailwind v4 |
| Storage | SQLite locally, PostgreSQL or MySQL in production; uploads on local disk or S3 |
| Infrastructure | External NATS (JetStream): KV, rate-limit windows, session cache, and the event bus |
| Observability | Prometheus on a dedicated 9091 listener, structured JSON logs, W3C traceparent |

:::note[Scope of these docs]
These docs are for **users**: how to run it, configure it, integrate with it, and extend it.
Internal plans, reviews, and ADRs stay in the repository's `docs/` directory.
:::
