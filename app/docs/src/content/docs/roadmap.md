## 已稳定

核心内容链路（版面 / 帖子 / 评论 / 互动）、认证与会话、权限与版面级继承、
可见性与门控、审核四模式、通知与 SSE、成长体系（XP / 等级 / 签到）、
站点自定义层、MCP 双向、观测（指标 / 日志 / trace）。

## 实验性

| 能力 | 状态 |
|------|------|
| 自治动议 | 可用，但前台入口较少 |
| 外部 MCP 审核委托 | 可用，需要自备外部服务 |
| 插件 | 仅声明式元数据，无执行扩展点 |

## 未实现 / 挂起

| 项 | 说明 |
|----|------|
| 移动端构建 | Capacitor 流程已挂起，恢复时需按 vinext 产物重新校订 |
| 多语言界面 | 目前只有 zh-CN，i18n 结构已在但未接英文 |
| 文档站多版本 | 单版本，结构已为版本化预留 |
| 前台 `/first-change-password` | 后端支持，前端未做页面（后台有） |

## 不打算做

| 想法 | 原因 |
|------|------|
| REST 风格 API | 与项目「动作式接口」的设计冲突 |
| 插件代码执行 | 等于开放 RCE |
| JWT 作为主凭证 | 服务端会话更适合「删行即失效」的语义 |
