## 内容与社区

| 能力 | 说明 |
|------|------|
| 版面 | 树形版面体系，支持图标、slug、排序、启禁、可见性（public / login / level） |
| 帖子 | 发帖、编辑、软删除进回收站、置顶、锁定、关闭、精华、修订历史、草稿 |
| 评论 | 嵌套评论、@提及、关注话题通知 |

| 搜索 | 帖子与全站搜索（后台有独立搜索页） |
| 通知 | 站内通知 + SSE 实时未读数推送 |

## 成长体系

XP 是**行为聚合**，不是累加计数器：

```text
total_xp = Σ(指标计数 × 当前 XP 规则) + Σ(连续签到里程碑) + Σ(人工调整)
```

意味着删帖、取消点赞、审核拒绝都会**自动回收**，改分值**立即对全员生效**。

| 能力 | 说明 |
|------|------|
| 等级 | 累计 XP 定级 + 滚动窗口保级，可升可降 |
| 签到 | 每日签到、连续天数阶梯奖励 |
| 徽章 | 默认徽章集 |
| 排行榜 | 积分 / 签到 / 发帖三榜 |
| 人工调整 | 管理员可加/减 XP 并附原因 |

配置全部后台可改：`/admin/levels`、`/admin/xp-rules`。

## 治理

| 能力 | 说明 |
|------|------|
| 审核模式 | `off` / `async`（默认）/ `external` / `manual` 四种 |
| 审核队列 | 待审内容人工通过或拒绝，每次判定留痕 |
| 举报 | 用户举报，后台处理 |
| 禁言 | 全局与版面两级，支持临时或永久 |
| 封号 | `role=ban`，登录即拒，并吊销全部会话 |
| 自治动议 | 社区投票类动议 |
| 门控规则 | 按条件自动 allow / deny / 转人工 / 限流 |
| 审计日志 | 管理操作与 MCP 调用都留审计 |

## 可见性

版面可设 `public`（游客可读）/ `login`（登录可读）/ `level`（达到等级才可读）。
有效策略沿祖先链取最严格一档。详情页在等级不足时返回 403 并提示所需等级。

## 站点自定义（不改代码改外观）

| 能力 | 说明 |
|------|------|
| 主题 token | 改主色、背景、圆角，支持明暗两套 |
| 自定义代码 | CSS / JS / HTML 片段，按位置注入 |
| 导航 | 自定义侧栏导航项 |
| 首页模块 | 最新 / 热门 / 版面 / HTML 模块 |
| 自定义页 | 独立的 Markdown 页面（`/p/{slug}`） |

**分级生效**：机器凭证（API Key / MCP）写 JS / HTML 类内容会被强制存草稿，
需人工启用——这是防止「AI 一把改坏整站」的闸门。

## 平台能力

| 能力 | 说明 |
|------|------|
| 认证 | 服务端会话、邮箱验证码、MFA（TOTP + 备份码） |

| OIDC SSO | Discovery / JWKS / Token / UserInfo |
| Webhook | 事件订阅、投递记录、重投、ping |
| 备份 | 创建 / 列表 / 下载 / 恢复 / 清理 |
| SEO | sitemap、robots、RSS 全部由后端独占生成 |
| 观测 | Prometheus 指标 + 结构化日志 + traceparent |
