## 技术栈

| 层 | 选型 |
|----|------|
| 后端 | Go + [Iris v12](https://www.iris-go.com/)，分层为 handler / service / repository，SQL 走 GORM |
| 前端 | React 19 + [vinext](https://github.com/vinext/vinext)（App Router）、TanStack Query、shadcn 风格原语、Tailwind v4 |
| 存储 | 默认 SQLite（本地）/ PostgreSQL（Compose）；文件可走本地磁盘或 S3 |
| 基础设施 | 外部 NATS（JetStream）承担 KV、限流、会话缓存与事件总线 |
| 观测 | Prometheus 指标（独立 9091 listener）+ 结构化 JSON 日志 + W3C traceparent |
