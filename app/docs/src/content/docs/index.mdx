## 技术栈

| 层 | 选型 |
|----|------|
| 后端 | Go 1.25 + [Iris v12](https://www.iris-go.com/)，handler / service / repository 分层，SQL 走 GORM |
| 前端 | React 19 + vinext（App Router）、TanStack Query、shadcn 风格原语、Tailwind v4 |
| 存储 | SQLite（本地）/ PostgreSQL / MySQL；文件走本地磁盘或 S3 |
| 基础设施 | 外部 NATS（JetStream）：KV、限流窗口、会话缓存与事件总线 |
| 观测 | Prometheus（独立 9091 listener）+ 结构化 JSON 日志 + W3C traceparent |
